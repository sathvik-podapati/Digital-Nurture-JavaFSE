# Exercise 6 - Library Management System

## Objective

Implement a Library Management System using Linear Search and Binary Search.

## Scenario

A library stores books and allows users to search by title.

## Project Structure

```
src/
└── com/
    └── cognizant/
        └── week1/
            └── library/
                ├── Book.java
                ├── SearchOperations.java
                └── Main.java
```

## Algorithms Used

- Linear Search
- Binary Search

## Time Complexity

| Algorithm     | Complexity |
| ------------- | ---------- |
| Linear Search | O(n)       |
| Binary Search | O(log n)   |

## Advantages

- Linear Search works on unsorted data.
- Binary Search is much faster for sorted data.

## Conclusion

Binary Search is the preferred choice for searching large collections of sorted books because it significantly reduces search time.
