# Exercise 3 - Builder Pattern

## Objective

Implement the Builder Design Pattern to construct a Computer object with multiple optional attributes.

## Scenario

A computer can have different configurations such as CPU, RAM, and Storage. Instead of using a constructor with many parameters, the Builder Pattern allows the object to be created step by step.

## Files

- Computer.java
- Main.java

## Design Pattern Used

Builder Pattern

## Output

```
CPU: Intel i7
RAM: 16GB
Storage: 1TB SSD
```

## Concepts Covered

- Builder Design Pattern
- Static Nested Class
- Private Constructor
- Method Chaining
- Object Creation
