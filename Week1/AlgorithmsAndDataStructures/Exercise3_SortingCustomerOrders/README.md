# Exercise 3 - Sorting Customer Orders

## Objective

Implement Bubble Sort and Quick Sort to sort customer orders based on total price.

## Scenario

An e-commerce application stores customer orders and needs to sort them by total order value.

## Project Structure

```
src/
└── com/
    └── cognizant/
        └── week1/
            └── sorting/
                ├── Order.java
                ├── SortingOperations.java
                └── Main.java
```

## Algorithms Used

- Bubble Sort
- Quick Sort

## Time Complexity

| Algorithm   | Complexity         |
| ----------- | ------------------ |
| Bubble Sort | O(n²)              |
| Quick Sort  | O(n log n) average |

## Advantages

- Bubble Sort is simple and suitable for small datasets.
- Quick Sort is efficient for large datasets and is commonly used in practice.

## Conclusion

Quick Sort is generally preferred because it performs significantly better than Bubble Sort on average for large collections of data.
