# Exercise 6 – Cursors

## Overview

This exercise demonstrates the use of Explicit Cursors in Oracle PL/SQL to process multiple records one at a time.

---

## Scenarios

### Scenario 1

Generate monthly statements for all customers.

### Scenario 2

Apply annual maintenance fee to all accounts.

### Scenario 3

Update loan interest rates based on the new bank policy.

---

## Concepts Covered

- Explicit Cursor
- OPEN
- FETCH
- CLOSE
- LOOP
- EXIT WHEN %NOTFOUND
- UPDATE
- DBMS_OUTPUT
