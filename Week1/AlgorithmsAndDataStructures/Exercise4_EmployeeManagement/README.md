# Exercise 4 - Employee Management System

## Objective

Implement an Employee Management System using arrays.

## Scenario

Store employee records in an array and perform add, search, traverse, and delete operations.

## Project Structure

```
src/
└── com/
    └── cognizant/
        └── week1/
            └── employee/
                ├── Employee.java
                ├── EmployeeManagement.java
                └── Main.java
```

## Data Structure Used

- Array

## Operations

- Add Employee
- Search Employee
- Traverse Employees
- Delete Employee

## Time Complexity

| Operation | Complexity |
| --------- | ---------- |
| Add       | O(1)       |
| Search    | O(n)       |
| Traverse  | O(n)       |
| Delete    | O(n)       |

## Advantages

- Fast random access using indexes.
- Simple implementation.
- Efficient for fixed-size collections.

## Limitations

- Fixed size.
- Costly insertion and deletion.
- Memory must be allocated beforehand.

## Conclusion

Arrays are suitable when the number of records is relatively fixed and fast indexed access is important.
