# Exercise 5 – Triggers

## Overview

This exercise demonstrates the use of PL/SQL Triggers to automate database operations and enforce business rules.

---

## Scenarios

### Scenario 1

Automatically update the LastModified date whenever a customer record is updated.

### Scenario 2

Maintain an audit log whenever a transaction is inserted.

### Scenario 3

Validate deposits and withdrawals before inserting a transaction.

---

## Concepts Covered

- BEFORE Trigger
- AFTER Trigger
- :NEW and :OLD
- Business Rule Validation
- RAISE_APPLICATION_ERROR
- Audit Logging
