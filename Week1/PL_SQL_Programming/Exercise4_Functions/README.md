# Exercise 4 – Functions

## Overview

This exercise demonstrates the use of **PL/SQL Functions** to perform common banking operations. Functions are reusable program units that return a single value and can be called from SQL statements or PL/SQL blocks.

---

## Scenarios

### Scenario 1 – Calculate Customer Age

Create a function to calculate the customer's age based on the Date of Birth (DOB).

### Scenario 2 – Calculate Monthly Loan Installment

Create a function that calculates the monthly installment using the loan amount, annual interest rate, and loan duration.

### Scenario 3 – Check Sufficient Balance

Create a function that verifies whether an account has sufficient balance before allowing a transaction.

---

## Concepts Covered

- PL/SQL Functions
- RETURN Statement
- Parameters
- SELECT INTO
- IF...ELSE
- Mathematical Calculations
- Date Functions
- Boolean Logic

## How to Execute

1. Open Oracle Live SQL.
2. Copy and execute the SQL script.
3. The function will be created successfully.
4. Execute the test block provided at the end of the script.
5. Verify the output using `DBMS_OUTPUT.PUT_LINE` or `SELECT` statements.

After completing this exercise, you will be able to:

- Create reusable PL/SQL functions.
- Return values from functions.
- Pass parameters to functions.
- Use functions in PL/SQL programs.
- Implement business logic using Oracle PL/SQL.
