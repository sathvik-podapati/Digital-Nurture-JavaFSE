# Exercise 2 - E-commerce Platform Search Function

## Objective

Implement Linear Search and Binary Search to search products efficiently.

## Scenario

An e-commerce platform stores products and allows users to search by product name.

## Project Structure

```
src/
└── com/
    └── cognizant/
        └── week1/
            └── search/
                ├── Product.java
                ├── SearchOperations.java
                └── Main.java
```

## Algorithms Used

- Linear Search
- Binary Search

## Time Complexity

| Algorithm     | Complexity |
| ------------- | ---------- |
| Linear Search | O(n)       |
| Binary Search | O(log n)   |

## Advantages

- Linear Search works on unsorted data.
- Binary Search is much faster for sorted data.

## Conclusion

Binary Search is preferred for large sorted datasets because it significantly reduces the number of comparisons required.
