# Exercise 7 – Packages

## Overview

This exercise demonstrates the use of Oracle PL/SQL Packages to group related procedures and functions into a single reusable program unit.

---

## Scenarios

### Scenario 1

Create a package to manage customer information.

### Scenario 2

Create a package to manage employee information.

### Scenario 3

Create a package to manage account operations.
